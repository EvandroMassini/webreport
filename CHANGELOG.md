# Histórico

## 0.1.0 — preparação para publicação

- Distribuição independente do visualizador, com API global existente.
- Documentação em português, catálogo CSV/JSON e matriz de suporte.
- Identificação de funções criadas/alteradas com assistência de IA.
- Dois exemplos executáveis sem servidor PHP nem dependências no navegador.
- Formulários demonstrativos de data, período, texto, constante e seleção simples/múltipla.
- Licença MIT com preservação dos créditos de Evandro / GWBM.
- Testes de regressão com Chromium e workflow GitHub Actions.
- Correções de configuração, média, validação de fórmulas e montagem de templates.
- Filtro HTML reforçado e formulários legados desabilitados por padrão.

Os arquivos instalados nos sistemas do autor não são substituídos por esta distribuição.
