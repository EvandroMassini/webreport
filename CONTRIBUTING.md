# Contribuindo

Use dados fictícios e descreva o comportamento esperado e observado. Para bugs de paginação, anexe um JSON mínimo e informe navegador, orientação, margens e tamanho de página.

Antes de propor alterações, execute `npm run check` e `npm test`. Ao mudar paginação, valide texto de um único nó, grupos que atravessam páginas, rodapés, registro único, PageBreaking e retrato/paisagem encadeados.

Preserve IDs de propriedades e assinaturas públicas. Mudanças incompatíveis devem ser documentadas no changelog e acompanhadas de instruções de migração. Não altere arquivos minificados como fonte; esta distribuição publica o JavaScript legível.

Comentários devem explicar decisões e invariantes. Identifique novas contribuições assistidas por IA sem substituir os créditos originais. Consulte [autoria](docs/authorship.md).

Contribuições aceitas serão distribuídas sob a licença MIT do projeto. Preserve o aviso de copyright e os créditos do desenvolvimento original.
